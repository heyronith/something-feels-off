# WO-000: Repo setup, Modal environment, model download, smoke test
Project: something-feels-off | Depends on: none | Est. compute: ≤ 0.5 A100-80GB GPU-hours (≈ $1.50) + CPU download

## Goal
Create a reproducible repo and Modal environment that loads Gemma-3-27B-it in bf16 on one A100-80GB, applies a residual-stream hook that provably changes outputs, and records throughput numbers needed to re-estimate the project budget.

## Context
- The repo https://github.com/heyronith/something-feels-off is empty. Default branch: main.
- The research studies activation steering on Gemma-3-27B-it. Later work orders inject vectors into the residual stream at layer 37 (of 62) and read activations at later layers. This WO builds only the foundation.
- Modal is already configured on this machine. A Hugging Face token already exists as a Modal secret, and the Gemma 3 license is accepted on HF.
- Reference implementation (read-only reference, do not copy code yet): https://github.com/safety-research/introspection-mechanisms at commit 5d5d9b485e293dc766c3a056cfe50283a7e435b6. It loads google/gemma-3-27b-it with AutoModelForCausalLM, attn_implementation="eager", and accesses decoder layers via model.model.language_model.layers.

### 4. Model loading (src/sfo/model.py)
- AutoTokenizer.from_pretrained and AutoModelForCausalLM.from_pretrained with torch_dtype=torch.bfloat16, attn_implementation="eager", revision=<sha>, device_map={"": 0}. Call model.eval() and set torch.set_grad_enabled(False).
- get_layers(model) returns the decoder layer list. Check model.model.language_model.layers first, then model.model.layers. Assert len == 62.
- Record d_model from the config (expected 5376). Assert it matches the hidden-state width observed in a forward pass.
- Chat formatting: a helper format_chat(messages) -> input_ids that uses tokenizer.apply_chat_template(..., add_generation_prompt=True, return_tensors="pt"). It must assert that exactly one BOS token appears at position 0 (no double BOS).

### 5. Reference code
Add safety-research/introspection-mechanisms as a git submodule at third_party/introspection-mechanisms, pinned to commit 5d5d9b485e293dc766c3a056cfe50283a7e435b6. Check whether the repo has a LICENSE file and record its status in the RUN_REPORT. Do not import from it in this WO.

### 6. Hooks (src/sfo/hooks.py)
- A context manager add_to_residual(model, layer_idx, vector, positions="all") registers a forward hook on decoder layer layer_idx. It adds `vector` (shape [d_model], bf16, on device) to the layer's output hidden states at the given positions, and removes the hook on exit, including on exceptions.
- The hook must handle the tuple output of the decoder layer: modify output[0] and return the tuple.
- A context manager capture_residual(model, layer_idxs) stores each layer's output hidden states (detached, moved to CPU as float32).
- Unit tests in tests/ check, on a tiny randomly initialized Gemma/Gemma3 text config on CPU (no download):
  - zero vector -> identical outputs;
  - non-zero vector -> changed outputs;
  - hooks are removed after the context exits and after an exception.

### 7. Budget ledger (src/sfo/budget.py)
Every Modal GPU function appends one row to results/budget_ledger.csv with: wo_id, function, gpu_type, start_utc, end_utc, seconds, est_usd, git_hash. Compute est_usd as:
  seconds × (0.000694 + 0.00003942 × n_cores + 0.00000672 × mem_gib)
using the cores and memory actually requested for the function.

### 8. Smoke test (scripts/wo_000_smoke.py, run on the GPU function)
Run these checks in order. Each one prints PASS or FAIL with numbers, and all results go to metrics.json.
1. Load: model loads; print n_layers, d_model, dtype of the first layer's weights (must be bf16), and peak GPU memory after load.
2. Tokenization: for these 5 prompts, print the formatted string, token ids, and decoded tokens. Confirm a single BOS.
3. Sanity forward: for the user message "Complete the sentence: The capital of France is", print the top-5 next tokens of the assistant turn. PASS if a token decoding to "Paris" (any leading space or casing) is in the top-5.
4. Determinism: two identical forward passes give bit-identical logits.
5. Zero hook: add_to_residual at layer 37 with a zero vector gives bit-identical logits to no hook.
6. Non-zero hook:
   - Take the mean L2 norm of the layer-37 residual over prompt 1's positions; call it r.
   - Add a fixed random unit vector (seed 0, torch.Generator) scaled to 4 × r at all positions.
   - PASS if max |Δlogit| at the last position > 1.0.
   - Print the top-5 next tokens before and after.
7. Hook removal: after the context exits, logits are bit-identical to the baseline again.
8. Capture: capture_residual on layers [37, 45] returns tensors of shape [1, seq_len, d_model] with no NaN or Inf.
9. Generation: greedy generation of 30 new tokens for prompt 2, with and without the non-zero hook from check 6 applied during generation. Print both texts.
10. Throughput (for budget re-estimation):
   (a) forward pass, batch 8 × 256 tokens: mean of 5 timed runs after 1 warm-up;
   (b) greedy generation, batch 8, prompt ≈ 64 tokens, 48 new tokens, with KV cache: tokens/sec, mean of 3 runs after 1 warm-up;
   (c) the same as (b) with the layer-37 hook active.
   Use left padding with an attention mask for batching, and assert the padding side is "left" for generation.
Seeds: torch.manual_seed(0), numpy seed 0, random seed 0.
