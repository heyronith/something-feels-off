# WO-003: Gate-engagement test on ordinary prompts (forward passes only)
Project: something-feels-off | Depends on: WO-002b (tip 7a79c16) | Est. compute: ≤ 0.8 A100-80GB GPU-h (≈ $2.50) + CPU download (~23 GB); no LLM judge

## Goal
Measure whether L37 concept/random steering changes Macar et al.'s three "gate" transcoder features (L45_F9959, L45_F74631, L50_F167) on ordinary prompts that contain no detection question. The comparison is the introspection prompt, which is the positive control. This is experiment E3 (it replaces the AUROC go/no-go).

## Specification

### 1. Transcoders
- **Repo:** `google/gemma-scope-2-27b-it`. Record the resolved commit sha.
- **Files:**
  - `transcoder_all/layer_45_width_262k_l0_big_affine/{config.json,params.safetensors}`
  - `transcoder_all/layer_50_width_262k_l0_big_affine/{config.json,params.safetensors}`
  - Use the **`_affine`** folders, not the plain `l0_big` ones.
  - Each params file is ≈ 11.4 GB fp32. Download both to the Modal volume `sfo-models` with a CPU function. Do not download `examples.safetensors`.
- **On GPU, load with `safetensors.safe_open`:**
  - **Full-layer encode (bf16):** `w_enc [5376, 262144]`, `b_enc` and `threshold`, cast to bf16.
  - **Gate columns (fp32):** `w_enc[:, g]`, `b_enc[g]` and `threshold[g]` for the gate ids, kept in fp32.
- **Encode (full layer, bf16):**
  ```
  pre  = x @ w_enc + b_enc
  acts = (pre > threshold) * relu(pre)
  ```
- **Gate pre-activation (fp32):**
  ```
  pre_g = x.float() @ w_enc[:, g].float() + b_enc[g].float()
  ```
- **Transcoder input x at layer ℓ** = the output of `model.layers[ℓ].pre_feedforward_layernorm`, i.e. the MLP input. Capture it with a forward hook on that module.
  - Also capture that module's **input** (the pre-MLP residual m, fp32), for the gate columns' direct-effect analysis (§5d).

### 4. Steering conditions
Steering is added to the L37 residual output with `add_to_residual_batched`, at positions ≥ the steering start.

| Class | Vectors | α | Rows |
|---|---|---|---|
| unsteered | none (α = 0) | 0 | 1 baseline + 2 noise-floor rows |
| concept | the 50 WO-001 concept vectors | 2, 4 | 100 |
| random | 20 Gaussian vectors (below) | 2, 4 | 40 |

- **Random vectors:** `torch.Generator` seeds 100–119, float32, standard normal in d_model. Random vector i is rescaled to norm α·‖v_{c_i}‖, where c_i is the i-th WO-001 concept (i = 0..19).
- **Noise-floor rows:** the 2 extra α = 0 rows sit in different batch slots from the baseline row.
- **Totals:** 143 rows per prompt × 266 prompts = 38,038 forwards.

### 5. Forward passes and captures
- **One prompt per batch.** All 143 condition rows for a prompt are split into consecutive batches of identical token ids (batch size of your choice, e.g. 24; record it). There is no padding.
  - The baseline α = 0 row goes in the first batch. The noise-floor rows go in a middle batch and the last batch.
- **Hook state.** Use a fresh `add_to_residual_batched` context **per forward**, and assert `state["abs_pos"] == T` after each forward. If the state isn't exposed, assert equivalently by re-entering the context per forward.
- **Settings:** `use_cache=False`.
- **Early halt:** for S5, S6 and S7, halt after layer 50's `pre_feedforward_layernorm` hook fires (raise and catch a private exception).
- **Full forward for logits:** for S1, S2, S2v, S3 and S4, run a **full** forward and record the last-token logits.

**Per row, capture:**
- **(a) Readout-position activations.** Transcoder activations at layers 45 and 50 at the readout position. Store them **sparse**: indices (int32) and values (float16) of all active features.
- **(b) Gate scalars at the readout position** (fp32): for each gate, pre_g, act_g and threshold_g.
- **(c) Gate means over the last 20 prompt tokens:** mean act_g and mean pre_g. This is the secondary readout. It uses the same window size in every set; it does not run from the steering start.
- **(d) Direct vs. indirect effect of steering on each gate** (steered rows only):
  - m_0 = the unsteered pre-MLP residual at the readout (the input to `pre_feedforward_layernorm` at ℓ = 45 or 50, from the baseline row).
  - Direct term:
    ```
    pre_g^direct = pre_g( LN_ℓ(m_0 + α·v) ) − pre_g( LN_ℓ(m_0) )
    ```
    where LN_ℓ is the model's own `pre_feedforward_layernorm` module at layer ℓ, and v is the steering vector of the row (α·v is the full injected vector).
  - Also store the actual Δpre_g = pre_g(row) − pre_g(baseline) and cos(w_enc[:, g], v).
- **(e) Residual scalars** at the readout position, entering layers 45 and 50 (the outputs of layers 44 and 49), fp32, with h_0 the baseline row:
  - `reach` = ‖h_s − h_0‖ / ‖h_0‖
  - `reach_indirect` = ‖h_s − h_0 − α·v‖ / ‖h_0‖
  - `dirproj` = ((h_s − h_0)·d_hat[44 or 49]) / ‖h_0‖
- **(f) Logits** (full-forward sets only): LD = logit("No") − logit("Yes") at the readout position, via `yes_no_token_ids`. Note the sign: positive means more "No".

### 6. Metrics (`scripts/wo_003_metrics.py`, CPU; report numbers only)
**Notation.** For a gate g, set S, α and class:
- D(S) = mean over (x, v) of Δpre_g.
- D_act(S) = mean of Δact_g.
- CIs use a hierarchical bootstrap: resample vectors, then prompts; 2,000 resamples; seed 0. Report both 95% and 99.44% CIs (99.44% = Bonferroni over 9 primary tests).

**Per gate × set × α × class, report:**
1. `base_pre_mean`, `base_margin_mean` (= mean of pre_g(x, 0) − threshold_g), and `base_active_frac`.
2. D(S) and D_act(S) with CIs.
3. `noise_floor`: the mean |Δpre_g| of the 2 noise-floor rows, averaged over prompts.
4. `rel_margin` = D(S) / mean|base_margin(S)|, with CI.
5. **Engagement ratios** on pre-activations, each with a CI from the shared-vector bootstrap and prompts resampled within each set. Also report the log|ratio| bootstrap distribution percentiles.
   - `R2` = D(S) / D(S2).
   - `R1` = D(S) / D(S1).
   - `R2v` = D(S) / D(S2v).
6. `pct_rank_active`: the percentile rank of D_act(S) among features **active in at least one row of S** at that layer (0 = most negative). Also report the count of such features and the gate's absolute rank.
7. `direct_frac` = mean pre_g^direct / mean Δpre_g, and the mean cos(w_enc_g, v).
8. **Matched-feature null:** take 200 features at the same layer whose `base_active_frac` and mean base activation on S fall within the same decile bin as the gate's, chosen with seed 0 among features active at baseline on S. Report their mean relative change in activation (median and IQR), next to the gate's.
9. **Secondary readout:** the same D with CIs for the last-20-token readout.

**Residual and logit summaries:**
- Per set × α × class: `reach`, `reach_indirect` and `dirproj` at both layers, each with a CI.
- For logit sets: mean ΔLD, plus the per-prompt correlation (Pearson, over steered rows) between Δpre_g and ΔLD, per gate.

**Inspection lists** (concept class, α = 4, per set and layer): the 20 features with the most negative and the 20 with the most positive D_act among active features. For each, give: id, D_act, base_mean, base_active_frac.

### 7. Figures

## Sanity checks (run and pass before the main run; record outputs)
1. Clean tree at a pushed HEAD (provenance gate).
2. **Transcoder config.** Print both `config.json` files. Assert:
   - `hf_hook_point_in == "model.layers.{ℓ}.pre_feedforward_layernorm.output"`;
   - `width == 262144`;
   - `affine_connection == true`;
   - the folder name ends in `_affine`.
   If a key name differs, stop and report it. Do not guess.
3. **Capture point.** On 1 prompt, the `pre_feedforward_layernorm` output must be bit-identical to the forward input of `model.layers[ℓ].mlp`.
4. **Early halt.** On 2 prompts, the layer-45 and layer-50 captures with the early halt must be bit-identical to those from a full forward.
5. **Identity and noise floor.** Within one batch, an α = 0 row must give captures bit-identical to the baseline row. Across batches, report the max |Δpre_g| between α = 0 rows. An α = 4 row must change the layer-45 capture. Assert that nothing is added at position 0 (BOS) in any row.
6. **Transcoder validity.** Use 3 unsteered S1 prompts and 3 unsteered S5 prompts, all positions except BOS.
   - Load `w_dec`, `b_dec` and `affine_skip_connection` for layer 45 temporarily, then free them.
   - Report the fraction of variance explained by `acts @ w_dec + b_dec + skip(x)` against the `post_feedforward_layernorm` output. Try both `skip(x) = x @ W` and `skip(x) = x @ W.T`, report both, and use the better one.
   - Report the mean L0 per token (the config says ≈ 120).
   - **STOP and report** if the best variance explained is < 0.5, or if the mean L0 is outside [30, 500].
7. **Gate-column consistency.** On 2 prompts, the fp32 gate `act_g` must match the bf16 full-encode activation within 2% relative, or both must be 0. Report any mismatch.
8. **Readout position.** For 2 prompts per set (unsteered, full forward), print the decoded final 5 prompt tokens, the readout token, and the top-5 next tokens with probabilities.
9. **Tokenization.** For 1 prompt per set, print the decoded prompt with the steering-start position marked.
10. **Gate presence.** Print pre_g, threshold_g and act_g for the 3 gates on all 6 S1 prompts, unsteered and at α = 4 for 3 concepts.
11. **Projected time.** After the first 5% of prompts, print the projected total GPU time. If it exceeds 1.0 h, stop and report.
