# WO-005a: Add the missing CIs to the WO-005 metrics (CPU)
Project: something-feels-off | Depends on: WO-005 (aba5637) | Est. compute: 0 GPU-h (CPU, < 20 min)

## Goal
Recompute `results/WO-005/metrics.json` from the existing raw files, adding every bootstrap CI that WO-005 §4 specified.

## Context
- `scripts/wo_005_metrics.py` currently emits point estimates only (`{"m": …}`) for:
  - logit LD_base, LD_steer, dLD and ratio_means;
  - the compression `yesward_resid`;
  - pooled delta_claim and D;
  - LOPO (leave-one-pair-out) estimates.
- WO-005 §4 requires a **cluster bootstrap**. Each replicate jointly:
  1. resamples the wording pairs P1–P6;
  2. resamples prompts/trials and vectors within each wording;
  3. resamples base samples within each prompt.
  - 2,000 resamples, seed 0, 95% CIs.
  - For the residuals, each replicate also re-fits the S4 compression model on resampled S4 prompts.
- **Raw inputs (unchanged):** `raw/logit_rows.jsonl`, `raw/gens.jsonl`.

## Specification
1. **Cluster bootstrap.** Implement it exactly as described in Context, and use it for every quantity listed there. Output `{m, lo95, hi95}` everywhere.
2. **Sets with no pairing structure.** For S3, S3T and S4, resample prompts and vectors independently. P0F and P0I are clustered by trial.
3. **Wilson CIs.** Add Wilson CIs for each per-cell claim rate. Label them `wilson_unclustered`.
4. **Raw-text table.** Add `raw/claims_by_pair.csv` with one row per (set, pair, cond) giving k, n, rate and Wilson CI.
5. **No other changes.** Do not change any definition, validity rule or threshold. Keep the old file as `metrics_noci_aba5637.json`.

## Sanity checks (a failed assert = stop and report)
1. Every point estimate equals its counterpart in `metrics_noci_aba5637.json` within 1e-9.
2. Every CI satisfies lo95 ≤ m ≤ hi95.
3. A test in `tests/test_wo005.py` checks that the cluster bootstrap on synthetic data with known variance gives a CI width within 20% of the analytic value.
