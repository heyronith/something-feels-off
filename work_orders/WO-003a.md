# WO-003a: Is gate suppression specific or generic damping? (CPU re-analysis)
Project: something-feels-off | Depends on: WO-003 (e5cd479) | Est. compute: 0 GPU-h; one **Modal CPU** job (≤ 64 GB RAM, ≤ 1 h)

## Goal
Using only the saved WO-003 captures, test whether steering suppresses Macar's gate features more than features with a similar baseline activation rank in the same prompt. Also measure how much of the steering-induced Yes/No shift at layers 45 and 50 the gates account for.

## Context
- **WO-003 outputs** live in `results/WO-003/raw/`. The `.pt` files are gitignored and exist **only on the Modal volume**, so run this WO as a Modal CPU function with the volume mounted.
  - `captures_sparse_L45.pt` and `captures_sparse_L50.pt`: sparse transcoder activations at the readout position, keyed by (set, prompt_idx, condition_id).
  - `conditions.json`, `gate_scalars.jsonl`, `logits_ld.jsonl`, `prompts.jsonl`.
- **Reuse:** `src/sfo/transcoder.py`, `scripts/wo_003_metrics.py` parsing helpers. Do not modify WO-003 outputs.
- **Gates (per-layer exclusion):** `{45: {9959, 74631}, 50: {167}}`.
- **Token ids:** Yes = 10784, No = 3771 (asserted via `sfo.ld.yes_no_token_ids`).
- No GPU and no new forward passes.

## Specification (summary)
- **A. Rank-matched null:** for each gate active at baseline, match 20 nearest-rank non-gate features (plus M50, M_noNo, M_norm, M_pre variants); report midrank percentile p and z; noise-floor null; concept−random contrast at α=4.
- **B. Damping:** proportional k and affine s fits excluding gates; turnover; gate prediction R²/slope.
- **C. DLA** at L45/L50 via `w_dec`, Δu = u_No − u_Yes, γ from final norm; gate/top-20/damping shares; Yes/No writers; validity correlations vs ΔLD.
- **D. Inspection** top-30 baseline-active features for selected prompts.
- **Figures:** `fig_rankmatched_pctl.png`, `fig_damping.png`, `fig_rho_vs_rank.png`, `fig_dla_share.png`.
