# WO-003a: Is gate suppression specific or generic damping? (CPU re-analysis)
Project: something-feels-off | Depends on: WO-003 (e5cd479) | Est. compute: 0 GPU-h; one **Modal CPU** job (≤ 64 GB RAM, ≤ 1 h)

## Goal
Using only the saved WO-003 captures, test whether steering suppresses Macar's gate features more than features with a similar baseline activation rank in the same prompt. Also measure how much of the steering-induced Yes/No shift at layers 45 and 50 the gates account for.

## Context
- **WO-003 outputs** live in `results/WO-003/raw/`. The `.pt` files are gitignored and exist **only on the Modal volume**, so run this WO as a Modal CPU function with the volume mounted.
  - `captures_sparse_L45.pt` and `captures_sparse_L50.pt`: sparse transcoder activations at the readout position, keyed by (set, prompt_idx, condition_id). They come from the bf16 full encode; values are stored as float16.
  - `conditions.json`: condition metadata, including the 2 noise-floor α=0 rows.
  - `gate_scalars.jsonl`: fp32 gate columns.
  - `logits_ld.jsonl`: LD = logit("No") − logit("Yes"), bf16 logits.
  - `prompts.jsonl`.
- **WO-003 code to reuse:** `src/sfo/transcoder.py` (`dense_from_sparse`, `safe_open` loader) and `scripts/wo_003_metrics.py` (set and condition parsing). Do not modify any WO-003 output.
- **Gates, per layer:** `GATES = {45: {9959, 74631}, 50: {167}}`. All gate exclusions below are **per layer**: at L45, exclude 9959 and 74631; at L50, exclude 167.
- **Token ids:** Yes = 10784, No = 3771. Hard-code them, and assert them against the tokenizer (`sfo.ld.yes_no_token_ids`).
- **Volume files:**
  - Transcoder params: `transcoder_all/layer_{45,50}_width_262k_l0_big_affine/params.safetensors` (`w_dec`, `b_enc`).
  - Model safetensors (Gemma-3-27B-it @ 005ad340) and their `model.safetensors.index.json` and `config.json`.
- No GPU and no new forward passes.
