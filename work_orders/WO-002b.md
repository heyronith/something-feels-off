# WO-002b: Paired shift-removal blocker (B1′), find and validate
Project: something-feels-off | Depends on: WO-002 (commit 02fd52a) | Est. compute: ≤ 1.0 A100-80GB GPU-h (≈ $3) + ≈ $1.30 OpenAI judge

## Goal
Build a corrected "noticing switch" (B1′) that removes only the **steering-induced** part of the residual along a concept-agnostic direction. The direction is estimated on a prompt that asks no question. Then test whether B1′ suppresses detection while preserving the injected content. This is experiment E2, second and final attempt. The WO-002 blocker (B1) failed because it clamped a yes/no-polarity axis and broke the model.

## Specification

### 0. Paired-twin execution (core mechanism; new module `src/sfo/paired.py`)
- Every steered example runs as a **pair in the same batch**: row i is the steered row and row i + B is its **twin**. The twin is the same tokens, with no steering and no blocker.
  - Both rows receive identical token ids and attention masks at every step.
  - In generation, the twin is **teacher-forced** on the token sampled for the steered row.
- **Steering hook:** layer 37 adds α·v_c to steered rows only (zero vector for twins), at positions ≥ start (padded coordinates, as in `add_to_residual_batched`).
- **B1′ hook** at each layer l in the blocker set L_blk, for steered rows only, at positions ≥ start:

  ```
  h_i ← h_i − ((h_i − h_{i+B}) · d̂_l) d̂_l
  ```

  This uses the twin's hidden state from the same forward pass. Twin rows are never modified.
- **B1′-null:** identical, but with a random unit direction per layer (seed 0).
- **Manual sampling loop** `paired_generate(...)`, with KV cache:
  - logits → divide by temperature → top-k (k = 64) → top-p (p = 0.95) → multinomial with a `torch.Generator` (seed per batch = 2000 + batch_index).
  - The sampled steered-row token is copied to its twin. Stop each pair at EOS (ids 1 or 106) or at max_new_tokens.
  - **All arms (none, B1′, B1′-null) in this WO use this loop**, so they are comparable. "none" = steering on, blocker off, twin present but unused.
- Unit tests (CPU, tiny config) in `tests/test_paired.py`:
  - (i) the twin row's logits equal an unpaired unsteered run on the same tokens;
  - (ii) with α = 0, B1′ is bit-identical to no blocker;
  - (iii) with a zero direction, B1′ is bit-identical to no blocker;
  - (iv) the greedy version of `paired_generate` with no hooks matches HF greedy `generate` token-for-token (10 tokens).

### Part A — direction on a non-question prompt (forward passes only)
**A1. Fixed tokens.**
- Prompt P_free = user `"Write two sentences about whatever comes to mind."`, chat template, single BOS.
- Generate ONE unsteered greedy continuation of 32 tokens. Fix the token sequence S = prompt + those 32 tokens, and save it.

**A2. Shifts.** For each dir-dev concept c (225):
- Run the pair on S with steering α·v_c at layer 37 at positions ≥ 1 (all except BOS).
- At every layer l ∈ 38..61, record the shift Δ_l = h_l(steered) − h_l(twin), averaged over positions ≥ 1. Keep a per-concept, per-layer mean shift vector (store float16).
- Also run 50 random Gaussian vectors (seeds 100–149), each scaled to ‖2·v_c‖ of the matching WO-001 concept, and record their mean shifts.

**A3. Directions.**
- d_l = mean over dir-dev concepts of the per-concept mean shift at layer l; unit-normalize to d̂_l.
- d_l^rand = the same over the 50 random vectors.

Report per layer:
- ‖d_l‖ and its ratio to the median twin residual norm (excluding BOS);
- cos(d̂_l, d̂_l^rand);
- cos(d̂_l, mean of v̂_c over dir-dev);
- max and 95th-percentile |cos(d̂_l, v̂_c)| over the 50 WO-001 validation concepts;
- **cos(d̂_l, d̂_l^WO-002)**, using the WO-002 direction from `results/WO-002/raw/directions.pt`;
- cos(d̂_l, d̂_{l+1}).

**A4. Selection sweep** (first 60 dir-dev concepts, n = 1, forward only). Candidate blocker sets L_blk = {l0, l0+1, …, 61} for l0 ∈ {38, 39, 40, 41}. For each, compute two quantities.
- **Detection recovery** on the introspection prompt (pairs, steering α = 4 from start_pos):

  ```
  rec = 1 − mean_c ΔLD_blk / mean_c ΔLD_none
  ```

  where ΔLD = LD(steered row) − LD(twin row) and LD = logit("Yes") − logit("No") at the last prompt position. The twin is unblocked, so ΔLD_blk compares the blocked steered row with the clean twin.
- **Content retention** on the forced-identification prompt (introspection n = 1 + prefill), at the position after the prefill:
  - p_c = the summed probability of the first tokens of `" " + w` and `" " + w.lower()` (deduplicated), where w is the concept word;
  - retention = mean_c p_c(blk) / mean_c p_c(none).

Compute both for B1′ and B1′-null.

**Pre-registered selection rule:** l0\* = the l0 with the highest B1′ recovery among those with retention ≥ 0.80. If none qualifies, choose the l0 with the highest retention, and flag it in the report.

**A5. Held-out (dir-val, 225, n = 1) at l0\*:** recovery and retention for B1′ and B1′-null.

**A6. Proxy validity.** Spearman correlation between per-concept retention-p_c(none) and WO-001 per-concept identification rates, over the 50 validation concepts (steered, no blocker).

### Part B — validate at l0\* with generation (the 50 WO-001 concepts)
Use temperature 1.0, top-k 64, top-p 0.95 via `paired_generate`. Arms are {none, B1′, B1′-null}.

| ID | Condition | Count |
|---|---|---|
| B-inj | Introspection, steered α=4, n=1..6, sampled, 100 tokens | 50×6×3 = 900 |
| B-fid | Forced identification, n=1..2, steered α=4, **greedy**, 6 tokens | 50×2×3 = 300 |
| B-exp | Concept expression, steered α=4 at positions ≥ 1, sampled, 64 tokens, 2 samples | 50×2×3 = 300 |

- **No unsteered runs are needed.** With α = 0, B1′ is the identity by construction; verify this in sanity check 4.
- **Judging:** B-inj gets claims-detection + identification, exactly as in WO-001. Report parse failures separately.
- **Concept match:** for B-fid and B-exp, the same rule as WO-002.
- **Degeneracy:** for every Part B generation, compute distinct-2 = unique whitespace bigrams / total bigrams. Flag it **degenerate** if distinct-2 < 0.5 or the response contains the same word ≥ 8 times in a row. Report the degenerate rate per condition × arm.
- **Steered-damage KL:** take 50 wikitext chunks (the first 50 of `results/WO-002/raw/wikitext_chunks.jsonl`) × the first 10 WO-001 concepts. Run pairs with steering α·v_c at positions ≥ 1 and the blocker at positions ≥ 1. Report:
  - mean per-position KL(p_twin ‖ p_steered) for each arm, where the "none" arm gives the steering-alone baseline;
  - the ratio KL_B1′ / KL_none.

### Metrics (report numbers only)
All rates use Wilson 95% CIs.
- Per arm: TPR, identification-given-detection, forced-identification rate, expression rate, degenerate rate (per condition), and the KL ratio.
- Relative changes vs none, with a bootstrap CI over concepts (2,000 resamples, seed 0).
- Part A: per-layer geometry, the sweep table, l0\*, held-out values, and the proxy correlation.

## Sanity checks (run and pass before the main runs; record outputs)
1. Clean tree / pushed-HEAD gate passes.
2. `tests/test_paired.py` passes on CPU. On GPU, check (i) and (iv) again with the real model on 2 prompts.
3. **Twin integrity during generation:** for 4 pairs, assert that twin and steered token sequences are identical at every step.
4. **Identity:** α = 0 with B1′ active gives bit-identical logits to no blocker (2 prompts); B1′ with a zero direction gives bit-identical logits.
5. **Removal correctness:** after B1′ at layer l, (h_i − h_twin)·d̂_l ≈ 0 at positions ≥ start, within 1e-3 × ‖h_i‖ (bf16). Positions < start are bit-identical to no blocker.
6. Print A1's fixed token sequence S (decoded).
7. **Projected GPU time:** after Part A, print the projected Part B time. If the total projected time exceeds 1.3 h, stop and report.
