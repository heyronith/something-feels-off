# WO-004: Causal gate test with ceiling, DLA-matched controls and a default-Yes probe
Project: something-feels-off | Depends on: WO-003 (e5cd479), WO-003a (7ab3446) | Est. compute: ≤ 0.7 A100-80GB GPU-h (≈ $2), hard cap 1.0 h

## Goal
Separate three explanations of the steering-induced shift toward "Yes" (ΔLD) on the introspection prompt:
- **(i) Margin compression.** Steering flattens every Yes/No margin toward zero.
- **(ii) Gate mediation through their direct logit effect.**
- **(iii) A dedicated downstream gate role.**

To do this, we clamp gates and controls under steering against a whole-MLP ceiling, and add a new "default-Yes" introspection prompt set.

### 2. Feature intervention (new `src/sfo/feature_clamp.py`)
**Capturing activations.** At ℓ ∈ {45, 50}, a hook on `pre_feedforward_layernorm` stores its output x. For each intervened feature f, compute the fp32 activation:

```
a_f = JumpReLU(x·w_enc[:,f] + b_enc[f], threshold[f])
```

**Adding the delta.** A hook on `post_feedforward_layernorm` adds, for each intervened row i and each covered position t:

```
delta_i(t) = Σ_{f∈F} (target_{i,f}(t) − a_{i,f}(t))·w_dec[f]
```

Compute it in fp32, then cast to bf16. Rows that are not intervened get no delta.

**Targets** come from the base row of the same batch, at the same layer and position:
- **clamp:** target = the base row's a_f(t).
- **sham:** target = a_f(t) of the steer_c row in the same batch.

**Whole-output replacement (clampMLP).** Replace the `post_feedforward_layernorm` output at L45 **and** L50 with the base row's output, at all positions.

**Weights.** Load `w_dec` rows and `w_enc` columns only for the needed features, via `get_slice`.

### 3. Control feature sets (pre-pass)
Run one unsteered full-encode forward per prompt (bf16, as in WO-003), at the readout position. The ranking key is the baseline activation a₀. Gates are excluded at each layer.

**M_dla(ℓ):**
- Candidates: non-gate features that are active at baseline and have raw dla > 0 (No-writers).
- Sort them by a₀·dla_raw in descending order.
- Add features greedily until Σ a₀·dla_raw ≥ the gates' Σ a₀·dla_raw at that layer.
- Stop at K = 50. Log K and the fraction of the gate total reached.
- If the gates are inactive at baseline at that layer, M_dla(ℓ) is empty. Log this.

**M_norm(ℓ):**
- Candidates: non-gate features active at baseline that are not in M_dla, with |normed dla| below that layer's 50th percentile of |normed dla|.
- Shuffle them with `numpy.random.default_rng([0, set_index, prompt_idx, ℓ])`.
- Add features until Σ a₀·‖w_dec‖ ≥ the gates' Σ a₀·‖w_dec‖.
- Stop at K = 50, and log K.

Save everything to `raw/controls.jsonl`.

### 5. Per-row logs
- LD.
- The top-5 next tokens.
- The RMS of the final residual at the last position: the input to `model.norm`, fp32. Call it rms_final.
- The gate activations at L45 and L50 at the last position, after any intervention.
- **For base and steer rows only**, decompose the `post_feedforward_layernorm` output at the last position, at L45 and L50, into three parts:
  - **features** = Σ_f a_f·w_dec[f] + b_dec (full bf16 encode);
  - **skip** = the affine skip term (use the orientation that won in WO-003 sanity 6, `W+A`);
  - **error** = the actual output − (features + skip).

  For each part, log its projection on Δu_n divided by rms_final ("DLA-equivalent").

### 6. Metrics (`scripts/wo_004_metrics.py`; numbers only)
**Basic quantities**
- ΔLD(row) = LD(row) − LD(base, same prompt).
- **Bootstrap:** two-way, resampling prompts and vectors independently; 2,000 resamples; seed 0. Report 95% CIs.
- **Leave-one-prompt-out:** report the S1, S3 and S8 point estimates with each prompt left out in turn.

**Per set × class × condition:** mean ΔLD, the mean signed LD, and P(LD < 0).

**Necessity** (for X ∈ {G, G_last, G45, Mdla, Mnorm, MLP}):
- N_X = mean(ΔLD_clampX − ΔLD_steer).
- Rec_X = N_X / N_MLP, as a ratio of means.
- Also report N_X / mean(−ΔLD_steer).

**Efficiency** (for X ∈ {G, Mdla}):
- N_X^lin = mean over rows of [Σ_{ℓ, f∈F_X} (a_base,f − a_steer,f)·dla_f(normed) / rms_final(steer)].
- Eff_X = N_X / N_X^lin.
- Report Eff_G − Eff_Mdla with a CI.

**Sufficiency:**
- Suf_G = mean(ΔLD_shamG) / mean(ΔLD_steer).
- Report |Suf_G − Rec_G·N_MLP/mean(−ΔLD_steer)| as the non-additivity index.

**Hydra check:** the L50 gate activation in clampG45 rows vs in steer and base rows. Report the fraction of the L50 gate suppression restored.

**Margin-compression model:**
- On S4 (diverse base LD), regress LD_steer on LD_base for each class (OLS; bootstrap over prompts).
- Predict the mean LD_steer for S1, S3 and S8 from their base LD.
- Residual = observed − predicted, with a CI.
- Also report the ratio mean LD_steer / mean LD_base per set.

**Decomposition** (steer vs base, at S1, S3, S4 and S8): the change in the DLA-equivalent of the features, skip and error parts at L45 and L50.

## Sanity checks
**All checks must pass. A failed assert means stop and report. Never loosen a threshold.**

1. **Clean pushed HEAD.**
2. **Identity** (2 S1 prompts). Each of the following must give logits bit-identical to its reference:
   - clamp with target = its own activations, vs no intervention;
   - clampG on an unsteered row, vs base;
   - clampMLP on an unsteered row, vs base;
   - sham with source = base, vs base.
3. **Delta check** (1 S1 prompt, 1 concept, L45). clampG and steer receive the same x. Check that post_ff_ln_out(clampG) − post_ff_ln_out(steer) = Σ_g (a_base,g − a_steer,g)·w_dec[g], within 1e-2 relative on the vector norm.
4. **Replication.** base and steer LD on S1 match WO-003 `logits_ld.jsonl` for the same (prompt, concept). Report the max |difference|. Stop if it exceeds 1.0: batch composition differs from WO-003, so exact equality is not expected.
5. **Group integrity.** Assert per batch that no group is split and that each batch starts with a base row.
6. **Readout.** Print the top-5 next tokens for base on every S8 prompt and on 2 prompts per other set. Also print them for the steer, clampG, clampMLP and shamG rows of the first concept on 1 S1 prompt.
7. **S8 default check.** Print the base LD for all 6 S8 prompts. Do not stop, whatever the values.
8. **Controls.** Print M_dla and M_norm (ids, a₀, dla, K, fraction reached) for the first 3 S1 prompts.
9. **Projected time.** After 5% of the prompts, project the total time. If it exceeds 1.0 h, stop.
